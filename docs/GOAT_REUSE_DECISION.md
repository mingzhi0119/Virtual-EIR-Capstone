# GOAT AI 复用边界与实施决策

日期：2026-10-08；状态：基线已验证，决策已采纳。对应 R4–R7。

1. 完整保留上游基线于 `apps/goat`，记录原提交；不修改原仓库，不扩展 sandbox、workbench 或只读 project_memory。
2. 先验证现有聊天、Ollama、前端构建及历史保存。部署只绑定 loopback，无登录模式不提供多人数据隔离承诺。
3. Capstone 专属创业对象、确认编辑和教练入口置于独立 `eir` 层，服务端通过现有 `POST /api/chat` 复用聊天，不改动 GOAT 生成 API 契约。GOAT 绑定 62606，EIR 绑定 62607，启动脚本统一管理；避免引入 mounted-app lifespan 或修改上游内部路由。
4. 创业状态单独 SQLite 存储，关联稳定 venture_id 与每次 session_id。保存背景、假设、证据、计划数量、完成数量及完整会话记录；用户显式确认事实，不从模型建议自动写入完成状态。自动摘要尚未实现，不作为已完成能力。
5. 每次会话先从数据库加载该项目当前状态。新会话不能依赖浏览器完整旧对话；显示状态来源并支持纠正。模型回复仅是建议，不是已确认事实。
6. 把完整 GOAT 聊天界面作为可用平台入口；最小 Virtual EIR 入口可以较薄，但必须真实使用上游聊天路径，而非仅更名或模拟回复。
7. 验证 happy path、失败、项目隔离、修正及新进程/重启持久化；真实 Ollama 两会话结果归档。自动测试 mock 模型，实测另存证据。

暂不做：登录/公网部署、语音、微调、多 agent 产品功能、Ain 未授权资料、云服务付费。代码可跨设备 Git 同步；运行数据必须另行备份，不能误称 Git clone 恢复模型或数据库。

实施增量：仅本 Capstone 导入的 GOAT subtree 补了 Ollama `think` 顶层字段兼容修复，未修改公开 HTTP 契约或原仓库。新增创业层与原平台能力分别归档。
