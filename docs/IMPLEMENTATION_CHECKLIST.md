## 实施边界

本地单用户、虚构案例、文字优先。服务只绑定 `127.0.0.1`，不把无登录 demo 暴露到局域网或互联网。代码通过 GitHub 同步；数据库、模型、依赖和日志不进 Git，换机需另行安全迁移数据。自动提取的资料不得未经用户确认覆盖事实；先实现显式编辑与保存。

R24 的静态展示是独立的、无后台读写能力的公开文件集；不改变上述本地服务边界，也不关闭 R14–R16。
